# Add one constraint

Invented prompts, not actual events. Let the table choose one, or use the first.

1. **No more reviewer time.** You cannot hire or add overtime for six months.
2. **Higher checking burden.** A client's audit requires a traceable source for every material claim.
3. **Demand doubles.** More clients want the service, but the team size is unchanged.
4. **Less data access.** The agent can use public information only.
5. **Less customer trust.** A prospective client will pay only after seeing a verified sample.
6. **Competitors catch up.** Rival firms can buy the same agent tools.

Ask: “Which response still works, what must change, and what would we test first?” A constraint is part of the thought experiment; it is not new evidence.
