# Start in an industry the table knows

Pick one task, one organization, and one proposed change. These are possible inquiries, not claims of existing deployments.

| Industry | A narrow question | A useful starting approach |
| --- | --- | --- |
| Professional services | Could a small firm prepare reliable briefs for smaller clients? | Simulation; prepared case available |
| Healthcare operations | Could agents reduce appointment follow-up work while keeping staff accountable? | Role playing; use fictional operations only |
| Real estate | Could a small team compare more properties using public information? | Research; check data access and verification |
| Retail | Could a small retailer test more product ideas without increasing inventory risk? | Problem solving; distinguish imagined from real customer reactions |
| Family-office administration | Could staff assemble better document summaries for human review? | Forecasting; use fictional documents and no personal financial information |

Before using a claim about current adoption, find a relevant original source or mark it unverified. The prepared case's numbers do not describe these industries. If the table wants numbers, ask it to supply clearly labeled hypothetical values.
